# 구매 패턴 기반 고객 페르소나 도출 후 채널 오분류 고객 마케팅 전략

**작성자:** 김정우, 안재원 · **작성일:** 2026-11-01

---

## 1. 분석 개요

**분석 주제**
도매업체 고객의 품목별 구매 데이터를 활용해 고객 유형을 군집화하고, 채널분류모형을 구축하여 페르소나별 채널을 확인한 뒤 채널 오분류 고객에 대한 마케팅 제안을 도출한다.

**분석 질문 (3단계)**
1. **군집**: 이 도매업체 고객은 몇 종류인가?
2. **분류**: 채널 정보 없이도 구분할 수 있는가?
3. **연결**: 각 페르소나가 어느 채널에 몰려 있는지 확인 후, 오분류 고객에 대한 마케팅 제안

**데이터**
- 출처: Cardoso, M. (2013) Wholesale customers (Kaggle)
- 440행 × 8열, 결측치·중복 0건
- 종속변수 `Channel`: 1=Horeca(호텔/레스토랑/카페, 67.7%), 2=Retail(소매유통, 32.3%)
- 독립변수 6개(연속형, 연간 구매액): `Fresh` 신선식품, `Milk` 유제품, `Grocery` 식료품, `Frozen` 냉동식품, `Detergents_Paper` 세제/종이류, `Delicassen` 즉석/가공식품
- **데이터 한계**: 수집 기간·화폐 단위 불명확 → "실제 마케팅 의사결정"이 아닌 "오분류 고객 식별·대응 방법론 검증" 목적으로 설계

## 2. EDA 핵심 발견

- 모든 구매액 변수가 **우측 꼬리 분포**(평균 > 중앙값, 왜도 2.5~11)이며, 상한 이상치가 변수당 4.5~9.8% 존재 → 로그/Yeo-Johnson 변환 필요
- `Region`은 `Channel`과 통계적 연관 없음(카이제곱 p=0.114) → 분석에서 제외
- **채널별 차이 (Mann-Whitney U test, 전부 유의, p<0.05)**

| 변수 | 채널1(Horeca) vs 채널2(Retail) | 판별력(\|Rank-Biserial\|) |
|---|---|---|
| Detergents_Paper | 채널1 < 채널2 | **0.92 (강함)** |
| Grocery | 채널1 < 채널2 | **0.88 (강함)** |
| Milk | 채널1 < 채널2 | **0.76 (강함)** |
| Frozen | 채널1 > 채널2 | 0.29 (약함) |
| Fresh | 채널1 > 채널2 | 0.22 (약함) |
| Delicassen | 채널1 < 채널2 | 0.20 (약함) |

- `Milk·Grocery·Detergents_Paper`(Retail 품목군) 간 강한 상관(Spearman 0.68~0.80) → PCA로 차원 축소

## 3. 전처리 · PCA

- 로그 변환 시 하한값(3) 때문에 `Fresh`·`Delicassen` 왜도가 과보정(-1.6) → **Yeo-Johnson 변환**으로 대체 (변환 후 왜도 ±0.1 이내)
- PCA: 주성분 3개로 **83.1%** 설명

| 주성분 | 설명력 | 주요 구성 변수 |
|---|---|---|
| PC1 | 44.9% | Milk·Grocery·Detergents_Paper (식료품·유제품·세제/종이류 축) |
| PC2 | 28.0% | Fresh·Frozen·Delicassen (신선·냉동·즉석식품 축) |
| PC3 | 10.2% | Fresh(+) vs Delicassen(-) 축 |

## 4. 군집분석 (페르소나 4종)

**k 선택**: 엘보우·실루엣·균형지수가 서로 다른 k를 가리켜(k=2, k=4, k=5) 혼란 → **시드 안정성(ARI)**으로 최종 판단
- k=4: 시드를 바꿔도 ARI **0.84~0.91**로 안정적
- k=5: 시드에 따라 ARI가 **0.48~0.97**까지 요동 (균형지수 1위는 특정 시드에서만 우연히 좋았던 결과)
- → **재현성 기준으로 k=4 최종 채택**

**4개 페르소나 (Channel 정보 없이, 구매 비중·규모만으로 군집화)**

| 군집 | 고객 수 | 총구매액 중앙값 | 주요 구매 비중 | Horeca:Retail | 페르소나 |
|---|---|---|---|---|---|
| C0 | 181 (41%) | 17,415 | Fresh 50%, Frozen 14% | **98.3% : 1.7%** | 소량 신선식품 중심형 |
| C1 | 78 (18%) | 26,498 | Grocery 40%, Milk 25%, Det_Paper 15% | 42.3% : **57.7%** | 중간 규모 식료품·유제품·세제/종이류 중심형 |
| C2 | 81 (18%) | 43,394 | Fresh 53%, Frozen 18% | **91.4% : 8.6%** | 대량 신선·냉동·즉석/가공식품 구매형 |
| C3 | 100 (23%) | 45,968 | Grocery 33%, Milk 23%, Det_Paper 14% | 13.0% : **87.0%** | 대량 식료품·유제품·세제/종이류 구매형 |

→ **구매 패턴만으로 채널이 자연스럽게 설명된다** (C0·C2는 Horeca 90%+, C3는 Retail 87%). 단, **C1은 채널이 섞여 있어** 오분류 발생 가능성이 가장 큰 자리로 미리 지목됨.

## 5. 채널예측 모델

**모델 선택 (Train 내부 StratifiedKFold 5, 누수 방지: 모든 전처리·군집화는 Train에만 fit)**

| 모델 | Accuracy | Macro F1 (mean±std) |
|---|---|---|
| **RandomForest (채택)** | 0.918 | **0.906 ± 0.031** |
| GradientBoosting | 0.912 | 0.899 ± 0.049 |
| SVM / KNN / LogisticRegression | 0.89~0.90 | 0.88~0.89 |

- 5개 모델이 0.88~0.91에 몰려 모델 간 우열은 크지 않음 → **"어떤 모델을 쓰든 구매 패턴만으로 채널이 약 90% 구분된다"**가 핵심
- **운영 근거는 교차검증 Accuracy 약 92%**를 쓴다 (Test 1회 95.5%는 표본 88명이라 표본오차가 커 참고만 함)
- **변수 중요도**: Detergents_Paper(0.342)·Grocery(0.227)·Milk(0.155) = 전체의 72% → **"Horeca는 신선식품을 많이 사서"가 아니라 "Retail 품목을 적게 사서" 구분됨**

## 6. 오분류 고객 분석 (Test 88명 중 4명, 4.5%)

| idx | 실제→예측 | 신뢰도 | 페르소나 | 유형 |
|---|---|---|---|---|
| 181 | Horeca→Retail | 0.52 (저신뢰) | C2 대량 신선·냉동형 | **규모 이상치형** |
| 342 | Horeca→Retail | 0.61 (저신뢰) | C1 중간규모형 | **카테고리 이탈형** |
| 223 | Retail→Horeca | 0.98 (고신뢰) | C0 소량 신선식품형 | **라벨-행동 불일치형** |
| 11 | Retail→Horeca | 0.997 (고신뢰) | C0 소량 신선식품형 | **라벨-행동 불일치형** |

**신뢰도 기준 2가지 유형**
- **저신뢰(0.52~0.61)**: 모델도 확신 못하는 경계 고객 → 성급한 결론 대신 검증 우선
- **고신뢰(0.98+)**: 모델은 확신하는데 라벨과 다름 → 등록 채널(Retail)과 실제 구매 행동(Horeca형)이 어긋난 고객

## 7. 가설 검증 결과

| 가설 | 결과 | 핵심 근거 |
|---|---|---|
| 가설1. 2개 이상 뚜렷한 소비 패턴 그룹 존재 | **부분 지지** | 4개 페르소나 도출되나 실루엣 0.28로 경계가 뚜렷하진 않음 |
| 가설2. Horeca=Fresh/Frozen, Retail=Grocery/Milk/Det_Paper | **부분 지지** | 비중은 가설대로나, 실제 판별력은 Retail 품목이 훨씬 큼 |
| 가설3. 오분류는 특정 패턴에 집중 | **경향 확인** (4명, 검정 불가) | 오분류 4명 모두 전형 패턴 이탈 고객이나 표본이 작아 통계적 검정 불가 |
| 가설4. 오분류 고객은 채널 전환/혼합형 | **부분 지지** | 고신뢰 오분류 2명이 뚜렷한 Horeca 페르소나(C0)에 속함, 단 라벨 오류 단정은 불가 |
| 가설5. 오분류 고객 구매액이 정분류와 다름 | **검정 불가** (기술적 비교만) | 오분류 중앙값(19,800) < 정분류 중앙값(28,503), 단 4명뿐이라 유의성 검정 불가 |

## 8. 오분류 고객 마케팅 전략

> **원칙**: 등록 채널(Channel)은 그대로 두고, 우리 쪽 서비스·제안을 실제 구매 행동에 맞춘다. 채널은 고객의 업종 정체성이라 "채널을 바꾸라"고 요구할 대상이 아니다. 예측신뢰도를 액션 강도로 쓴다 — 높을수록 즉시 실행, 낮을수록 검증부터.

| 유형 | 고객 | 신뢰도 | 핵심 액션 |
|---|---|---|---|
| **라벨-행동 불일치형** | 223, 11 | 0.98+ | 등록 채널 유지, 내부 서비스만 Horeca 기준 전환(신선·냉동 카탈로그 우선 노출, 정기배송, 전담 영업사원), 영업 실사로 업태 변화 확인 |
| **카테고리 이탈형** | 342 | 0.61 | 최근 발주 이력 검증 → Fresh 타 공급처 조달 중이면 시범가·소량 납품 제안 |
| **규모 이상치형** | 181 | 0.52 | 마케팅 대상 아님 → Key Account(핵심 거래처) 관리로 분리, 전담 계정관리자·개별 계약 |

- **운영 방안**: 채널예측 모델로 "예측 ≠ 등록 채널 & 신뢰도 0.9+" 고객을 정기 추출해 영업·마케팅 우선순위 리스트로 활용

## 9. 한계 및 향후 과제

- **표본 한계**: 전략 근거가 Test 88명 중 4명뿐 → `cross_val_predict`로 440명 전원의 검증 예측을 만들면 표본 확대 가능
- **군집 안정성**: k=4 실루엣 0.281로 약함, 시드에 따라 경계 고객의 소속이 바뀜(ARI 0.84~0.91) → 경계 고객 해석 시 주의 필요
- **데이터 한계**: 수집 시점·연도 불명으로 현재 시장에 바로 적용하기 어려움
- **실행 검증**: 제안 전략은 데이터 기반 가설 → 실제 적용 전 파일럿(A/B 테스트)으로 효과 검증 필요
